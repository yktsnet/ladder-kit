# 採点する

1人を採点し、次に上げる軸を1つ決めるまでの手順である。

## 手順

1. **軸ごとに、判定文の下から順に真偽を見る。** [ladder.md](ladder.md) の「読むもの」列が
   どこを開くかを指している。L2 が真なら L3 へ進み、偽になった手前がその軸の点になる
2. **証拠が無い軸は「未観測」として残す。** 点で埋めない
3. **5軸の点を並べる。** 揃わないのが普通である
4. **最も低い軸を、次に上げる1軸にする。** 未観測は選ばない

## 未観測を点で埋めない

判定文は成果物から確かめられる事実で書いてある。そのまま読むと、測っているのは
**やってきたこと**になる。組めるが組む仕事をしなかった人は、E が低く出る。

**段階は能力の側で決める。** 機会が無かっただけの人を下に置くと、育成で打つ手を間違え、
選考では取り逃す。

未観測は下限ではない。育成では機会を配れば分かる軸、選考では面接で聞く軸を指す。

## 点から人のレベルを決めるとき

5軸の点が揃わないとき、どこを取るかは用途で変わる。

- **育成** — 最も低い軸を見る。次に上げる1軸がそのまま出る
- **配置** — 案件が要求する軸だけを見る。5軸の平均は取らない
- **選考** — 最も低い軸を見る。ただし B は入社前に測れない（[hiring.md](hiring.md)）

平均を取ると、凸凹が消えて「次に何をするか」が出なくなる。点は順位付けではなく、
どこが空いているかを見るために置いてある。

## 候補者に当てるとき

軸と段階は共通で、証拠源だけが替わる。手順は [hiring.md](hiring.md) にある。

## 育成に使うとき

処方箋を別に持たない。**次に上げる1軸に対応する手順を回させる**ことが処方箋になる。
教育メニューを別立てにすると、育成のための作業と実務が二重になり、育成側だけが先に止まる。

型を回せば標準の形の成果物が出る。それが次の採点の証拠になる。

## 採点結果が型の欠陥を指すとき

同じ軸の同じ段階で、複数人が同時に止まっているなら、人ではなく型を疑う。

L2 の判定文は、型が実際に強制するものだけで書いてある。理解した人が L2 に届かないなら、
**判定文か型のどちらかが間違っている。** この場合に直すのは人ではなく型の側である。
