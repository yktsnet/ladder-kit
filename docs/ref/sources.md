# 下敷きにした公開物

軸 × 段階のセルに判定文を置く様式は、公開されているキャリアラダーから引いている。
ここでは出所と、引き継ぐもの・落とすものを記す。

## 参照先

| 出所 | ライセンス | 引いたもの |
|---|---|---|
| [jorgef/engineeringladders](https://github.com/jorgef/engineeringladders) | Apache-2.0 | 軸を分けたうえで、各セルに1文の判定を置く様式 |
| [Medium/snowflake](https://github.com/Medium/snowflake) | Apache-2.0 | 軸ごとに段階を刻み、非エンジニアにも読める物差しとして公開した形 |
| [mercari/mercari-engineering-ladder](https://github.com/mercari/mercari-engineering-ladder) | CC0-1.0 | 段階を、任せられる範囲の広さで刻む書き方 |
| [bmoeskau/engineering-ladders](https://github.com/bmoeskau/engineering-ladders) | MIT | 公開ラダーを集めたもの。軸の立て方の分布を見るために読む |
| [progression.fyi](https://progression.fyi/) | 各フレームワークに従う | 同じくカタログ。分野をまたいで集めてある |

文面は転記していない。引いたのは表の構造と、段階の刻み方である。

## 引き継ぐもの

- 軸 × 段階の表形式と、セルごとに1文の判定を置く様式
- 段階を、任せられる範囲の広さで刻むこと

## 落とすもの

- **報酬帯との対応。** 市場と案件構成で動くため、物差しの側に固定しない
- **調達チャネルの使い分け。** 誰をどの契約形態で取るかは、物差しではなく各社の事情で決まる
- **抽象語による判定文。** 可搬性と引き換えに、採点が評価者の解釈勝負になる
