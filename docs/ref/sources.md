# 下敷きにした公開物

軸 × 段階のセルに判定文を置く様式は、公開されているキャリアラダーから引いている。
ここでは出所と、引き継ぐもの・落とすものを記す。

## 参照先

| 出所 | 引いたもの |
|---|---|
| [progression.fyi](https://progression.fyi/) | 公開ラダーのカタログ。軸の立て方の分布を見るために読む |
| [Medium: Engineering Growth Framework (Snowflake)](https://github.com/Medium/snowflake) | 軸ごとに段階を刻み、非エンジニアにも読める物差しとして公開した形 |
| [Rent the Runway: Engineering Ladder](https://github.com/RentTheRunway/engineering-ladder) | 軸を分けたうえで各セルに判定文を置く様式 |
| [Khan Academy: Engineering Career Development](https://engineering-career-dev.khanacademy.org/) | 段階の記述をスコープの拡大で刻む書き方 |

## 落とすもの

- **報酬帯との対応。** 市場と案件構成で動くため、物差しの側に固定しない
- **抽象語による判定文。** 可搬性と引き換えに、採点が評価者の解釈勝負になる

## 引き継ぐもの

- 軸 × 段階の表形式と、セルごとに1文の判定を置く様式
- 段階を、任せられる範囲の広さで刻むこと

ライセンスは参照先ごとに異なる。文面を転記する場合は個別に確認する。
