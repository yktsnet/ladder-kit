# ladder-kit

AI エージェントで開発を回すチームのための、エンジニア評価の物差し。

軸と段階で座標系を1つ作り、現在地と到達像を同じ物差しの上に置く。評価そのものが目的ではなく、
次に上げる軸を決めるために読む。

既存の公開キャリアラダーと違うところは3つある。

- **判定文を成果物への参照で書く。** 「自律的に」「複雑な」といった評価者の解釈に委ねる語を
  使わず、リポジトリの何を開けば真偽が確かめられるかまで書く
- **標準化されたワークフローの運用を独立した軸として持つ。** エージェントを走らせる開発では、
  配られた型に乗れるかどうかが個人の書き方の巧拙より先に効く
- **同じ物差しを、評価・育成・採用の3つに当てる。** 軸と段階は共通で、替えるのは証拠源だけに
  する。社内は成果物から、候補者は面接と経歴から読む。育成の処方箋も別立てにせず、
  配られた型を回すこと自体に載せる

型の配布そのものは扱わない。配る側は [sdlc-kit](https://github.com/yktsnet/sdlc-kit) が持ち、
ここはそこに乗れているかを測る。
